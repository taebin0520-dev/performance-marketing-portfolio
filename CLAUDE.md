## Technical Scope

Use beginner-friendly and interview-explainable code.

Required skills:

- Python basics
- Pandas
- NumPy basics
- Matplotlib
- SQL logic
- CSV analysis
- Basic marketing metrics

Do not overuse advanced code that the user cannot explain in an interview.

Prefer readable code over clever code.

## Key Marketing Metrics

Always explain and calculate when relevant:

- CTR = clicks / impressions
- CPC = cost / clicks
- CVR = conversions / clicks
- CPA = cost / conversions
- ROAS = sales / cost * 100

When calculating these metrics, also explain what each result means from a performance marketing perspective.

## Customer Analysis Scope

Include:

- Customer purchase count
- Total purchase amount
- Last purchase date
- Average order value
- 30/60/90-day inactive customers
- Churn-risk customers
- CRM campaign suggestions
- Customer segment interpretation
- Practical retention campaign ideas

## Coding Rules

- Write readable code.
- Add beginner-friendly comments.
- Explain how to run the code.
- Include expected output.
- Explain common errors and how to fix them.
- Connect every analysis result to performance marketing decisions.
- Avoid unnecessary abstraction, complex classes, or advanced syntax unless there is a clear reason.
- If advanced syntax is used, explain it simply.

## Data Safety Rules

- Do not use real personal information.
- Do not include passwords, API keys, tokens, phone numbers, addresses, account numbers, or private customer data.
- Use only sample data, fake data, or public data.
- If a dataset looks sensitive, warn the user before using it.
