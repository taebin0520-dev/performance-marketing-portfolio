# 검색광고 키워드 전략 리포트

**작성자:** 강태빈  
**목적:** 네이버·구글 검색광고 키워드 구조 설계 및 입찰 전략 제안  
**카테고리:** 패션 커머스 (예시 브랜드 기준)

---

## 1. 키워드 전략 개요

검색광고에서 키워드는 "어떤 고객을 광고에 노출할지 결정하는 필터"입니다.  
이 리포트는 구매 의도가 높은 키워드를 우선 확보하고, 비용 효율을 높이는 구조를 설계합니다.

### 키워드 매칭 유형 (네이버·구글 공통)

| 매칭 유형 | 설명 | 예시 |
|-----------|------|------|
| 확장 매칭 | 유사 검색어까지 넓게 노출 | "여성 티셔츠" → "여자 반팔", "여성의류" |
| 구문 매칭 | 키워드 포함 검색어에만 노출 | "여성 티셔츠"를 포함하는 검색어만 |
| 일치 매칭 | 정확한 키워드와 거의 동일한 검색어 | "여성 티셔츠"만 |

> **전략 원칙:** 처음에는 구문/일치 매칭으로 시작하여 의도 외 클릭 낭비를 막고,  
> 데이터 축적 후 성과 좋은 검색어를 별도 그룹으로 이동

---

## 2. 키워드 구조 설계 (SKAGs 방식)

**SKAG (Single Keyword Ad Group):** 광고 그룹 하나에 키워드 하나만 배치하는 구조.  
키워드-광고문구-랜딩페이지 일관성을 높여 품질지수와 CVR을 개선합니다.

### 캠페인 구조 예시

```
캠페인: [브랜드명] 패션
├── 광고그룹 01: 브랜드 키워드
│   ├── [일치] 브랜드명
│   └── [구문] 브랜드명 쇼핑
│
├── 광고그룹 02: 핵심 상품 키워드 (구매 의도 高)
│   ├── [구문] 여성 청바지 추천
│   ├── [구문] 봄 원피스 구매
│   └── [구문] 20대 여성 패션
│
├── 광고그룹 03: 경쟁사 키워드
│   ├── [일치] 경쟁브랜드A
│   └── [구문] 경쟁브랜드A 비교
│
└── 광고그룹 04: 정보성 키워드 (구매 의도 低)
    ├── [구문] 봄 코디 추천
    └── [구문] 여성 패션 트렌드
```

## 3. 키워드 분류 및 입찰 전략

### 구매 의도별 키워드 분류

| 분류 | 키워드 예시 | 입찰 전략 | CPC 예상 |
|------|------------|-----------|----------|
| 구매 의도 高 | "여성 청바지 구매", "봄 원피스 할인" | 적극 입찰, CPA 목표 | 500~1,500원 |
| 구매 의도 中 | "20대 봄 패션", "여성 캐주얼 추천" | 중간 입찰, CVR 모니터링 | 200~500원 |
| 인지/정보 | "봄 코디 방법", "패션 트렌드 2024" | 낮은 입찰, 브랜드 노출 목적 | 100~200원 |
| 브랜드 방어 | "[경쟁사명] 대안", "[경쟁사명] 비교" | 중간 입찰 | 300~700원 |

### 제외 키워드 (Negative Keywords) 설정

불필요한 비용을 막기 위해 반드시 제외해야 할 키워드:

- 무료, 공짜, 쿠폰코드, 중고, 취업, 채용
- 경쟁사 브랜드명 (브랜드 방어 그룹 제외 시)
- 이미지 (예: "여성 패션 이미지" → 구매 의도 없음)

## 4. 품질지수 관리 전략

네이버·구글 모두 품질지수(Quality Score)가 높을수록 동일 CPC로 더 좋은 노출 순위를 받습니다.

**품질지수 구성 요소:**
1. CTR (광고 클릭률) — 가장 중요
2. 광고 관련성 (키워드 ↔ 광고문구 일치도)
3. 랜딩페이지 경험 (로딩속도, 모바일 최적화, 키워드 포함 여부)

**개선 체크리스트:**
- [ ] 광고문구에 키워드 포함 여부 확인
- [ ] 랜딩페이지 URL이 광고 그룹 테마와 일치하는지 확인
- [ ] 모바일 랜딩페이지 로딩 3초 이내
- [ ] CTR 1% 미만 광고문구 교체 (A/B 테스트)

---

## 5. 입찰 전략 유형 비교

| 전략 | 설명 | 적합한 상황 |
|------|------|------------|
| 수동 CPC | 직접 입찰가 설정 | 예산 소진 방지, 소규모 캠페인 |
| 타겟 CPA | 목표 전환 비용 자동 최적화 | 전환 데이터 30건 이상 확보 시 |
| 타겟 ROAS | 목표 수익률 기반 자동 최적화 | 수익 데이터 충분히 축적된 캠페인 |
| 클릭수 최대화 | 예산 내 클릭 수 극대화 | 브랜드 인지도 초기 확장 |

> **초보 퍼포먼스 마케터 팁:** 전환 데이터가 부족할 때는 수동 CPC로 시작,  
> 30전환 이상 쌓이면 타겟 CPA로 전환해 자동화 효율을 높이세요.

---

## 6. 월간 키워드 관리 루틴

| 주기 | 작업 내용 |
|------|----------|
| 매일 | 예산 소진율 확인, 이상 CPC 체크 |
| 매주 | 검색어 보고서 분석 → 제외 키워드 추가 |
| 격주 | 광고문구 A/B 테스트 결과 적용 |
| 매월 | 키워드별 CPA/ROAS 검토 → 입찰가 조정 |
| 분기 | 신규 키워드 발굴, 시즌 키워드 준비 |
