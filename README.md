# 성과 마케팅 포트폴리오

이 저장소는 아토모스 퍼포먼스 마케터 취업을 목표로 만든 포트폴리오 저장소입니다.

## 목표

- 광고 성과 분석 포트폴리오 제작
- 고객데이터 분석 및 고객이탈 분석 포트폴리오 제작
- 검색광고 키워드 전략 리포트 제작
- SQL, Python, Pandas, 데이터 시각화 역량 증명
- 퍼포먼스 마케팅 지표 분석 역량 증명

## 주요 분석 주제

1. 광고 성과 분석
   - CTR
   - CPC
   - CVR
   - CPA
   - ROAS

2. 고객데이터 분석
   - 고객별 구매횟수
   - 총구매액
   - 최근 구매일
   - 평균 주문금액
   - 이탈 위험 고객군 분류

3. 검색광고 전략
   - 핵심 키워드
   - 확장 키워드
   - 제외 키워드
   - 광고그룹 구조
   - 광고문안 예시

## 폴더 구조

- data: 분석용 CSV 데이터
- notebooks: Jupyter Notebook 분석 파일
- scripts: Python 분석 코드
- reports: 분석 보고서
- images: 그래프 및 시각화 이미지
- docs: 검색광고 전략 문서 및 기타 자료

## 사용 예정 기술

- Python
- Pandas
- NumPy
- Matplotlib
- SQL
- Google Sheets
- Google Ads
- GA4 기초
