# 성과 마케팅 포트폴리오

이 저장소는 아토모스 퍼포먼스 마케터 취업을 목표로 만든 광고 데이터 분석 포트폴리오입니다.

## 목표

- 광고 성과 분석 포트폴리오 제작
- 고객데이터 분석 및 고객이탈 분석 포트폴리오 제작
- 검색광고 키워드 전략 리포트 제작
- SQL, Python, Pandas 기반 데이터 분석 역량 증명
- CTR, CPC, CVR, CPA, ROAS 등 퍼포먼스 마케팅 지표 분석 역량 증명

## 주요 분석 주제

1. 광고 성과 분석
2. 고객데이터 분석 및 고객이탈 분석
3. 검색광고 키워드 전략

## 사용 예정 기술

- Python
- Pandas
- NumPy
- Matplotlib
- SQL
- Google Sheets
- Google Ads
- GA4 기초
